# 接力消息模板

> 由 `oversight-relay` 填写，由 `oversight-safety` 审核，由**用户**发送。
> 本库不能自动投递。见 `docs/spec/relay-protocol.md`。

## 目标会话

```
session_id: 
会话名称: 
停滞点: 
触发条件: (b) 停滞 / (c) 重复失败 / (d) 手动
```

## 草稿

> 硬性要求：≤5 行、≤1 个命令块、带具体下一步、带决策授权、不重复已有上下文。

```
（在此写入草稿正文）
```

## 三要素自检

| 要素 | 是否具备 | 说明 |
|---|---|---|
| 停滞点定位（用事实，不是猜测） | | |
| 具体下一步（可执行命令或明确动作） | | |
| 决策授权（「如果 A 不行就做 B，不用问」） | | |

## 红线自查（relay 自填，safety 复核）

| # | 红线 | 是否触碰 |
|---|---|---|
| 1 | 不可逆删除 | 否 |
| 2 | 向外发送（邮件/消息/PR/force push） | 否 |
| 3 | 金钱交易 | 否 |
| 4 | 权限变更 | 否 |
| 5 | 凭据操作 | 否 |
| 6 | 与原始需求矛盾 | 否 |
| 7 | 本机绝对路径 | 否 |
| 8 | 替用户承诺未授权的事 | 否 |
