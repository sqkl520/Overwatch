## 为什么 §3 永远做不到

ADR-0001 记录的实测结论：目标会话正在运行时，`--resume` 落到副本上，
你的窗口里不会出现任何东西。宿主虽有跨会话消息通道，但投递必须标注来源，
无法做到「无痕模仿用户」。

所以凡是以「自动接力」为前提的设计（§1 的分级、§3 的投递、§5 的演进），
**都建立在一个不成立的前提上**。它们仍保留，是因为里面的数据与推理过程有价值，
不是因为它们还能被实施。
