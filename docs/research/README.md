## 维护规则

1. **新增报告必须在本页登记**，并给出状态与依据。没有状态的研究报告等于没有结论。
2. **状态只升不降的除外**：✅ 可以被后续报告降级为 ⚠️ 或 ❌，降级时**必须在「已被推翻的结论」表里加一行**，写清正确说法。
3. **不要改历史报告里的数字。** 它们是当时的实测记录，改了就没有证据价值。要更正就写新报告，然后在这里改状态。
4. **本页自己也要被核。** 上面每一行「依据」都是一条可复算的线索；发现某行依据不成立时，改那一行，不要整页重写。
