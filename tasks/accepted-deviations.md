> 记录**已知但本轮不修**的偏差。审查时，本文件列出的条目**不计入判定**。

## 台账

### AD-001 不能自动接力，只能产出草稿

- **偏差**：原始设计稿 §1 要求「会话写入不可降级」，本库做不到。
- **为什么接受**：宿主的 `--resume` 对运行中会话会产生副本分叉；跨会话消息通道强制标注来源，无法无痕。见 `docs/adr/0001-config-only.md` §代价·3。
- **复核条件**：宿主提供对运行中会话的、可控制来源标注的稳定注入接口。
- **复核日期**：2026-10-29（下次复核：出现上述能力时）

### AD-002 四态判定没有运行时强制力

- **偏差**：主线程可以自称 `PRODUCING` 绕过判定，因为判定靠约定而非代码。
- **为什么接受**：纯配置库形态的固有代价。缓解措施：`scripts/scan-sessions.mjs` 独立从 transcript 计算，主线程写 `state.json` 时必须附脚本输出摘要。
- **复核条件**：误判导致实际损失，或用户要求升级为运行时形态。
- **复核日期**：2026-10-29

### AD-003 心跳是事后重建，不是实时上报

- **偏差**：规格 §5.2 要求「心跳间隔 >3 分钟 → FAILED」，实时监控。本库只能在下一轮读取时发现。
- **为什么接受**：无常驻进程。且实测固定 180s 会误判 63.1% 的会话（1275/2021），已改为会话自适应 p95（`docs/spec/state-model.md` §4.2）。
- **复核条件**：宿主提供实时 hook 或 `claude agents --json` 的频率足以支撑准实时轮询。
- **复核日期**：2026-10-29

### AD-004 token 预算只能估算

- **偏差**：状态行的 `budget` 是代理指标（调用次数 × 平均开销），不是真实用量。
- **为什么接受**：**前台交互会话**的 token 消耗在派发时不可知，中途不可查，只能用代理指标并标 `est:`。
  后台作业例外：`~/.claude/jobs/<id>/state.json` 有真实 `tokens`（实测 3,475,667 量级），能关联 job 的会话必须显示真实值。
- **复核条件**：宿主暴露子 Agent 的实时 token 用量。
- **复核日期**：2026-10-29

## 复核流程

每轮 run 开始前，主线程扫一遍本文件：

1. 复核条件已满足的 → 移入 `dev-findings.md` 并标 `triaged`
2. 复核条件仍不满足的 → 更新复核日期
3. 条目描述的偏差已消失的 → 删除，并在 CHANGELOG 记录
